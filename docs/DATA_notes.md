# Data notes (SciCite & ACL-ARC)

## SciCite
- **Source**: [allenai/SciCite](https://github.com/allenai/SciCite) — *Structural
  Scaffolds for Citation Intent Classification in Scientific Publications*, Cohan et al., NAACL 2019.
- **Official download** (mirrored below; 22.1 MB):
  `https://s3-us-west-2.amazonaws.com/ai2-s2-research/scicite/scicite.tar.gz`
- **Size**: 10,969 annotated citations from 6,627 papers (computer science + biomedicine).
- **Splits**: train 8,194 / dev 916 / test 1,859.

### Labels
| field | classes | meaning |
|-------|---------|---------|
| `label` (primary) | **background, method, result** | the 3-class task used for the headline numbers |
| `label2` (fine-grained) | 4-class variant | optional secondary experiment |

### Fields used
```
string          citing paragraph containing the citation  (model input)
sectionName     section of the citing paper
label           3-class intent
citingPaperId   / citedPaperId   paper ids (via Semantic Scholar API)
```

## ACL-ARC
- **Source**: Jurgens et al. (2018); preprocessed copy in the SciCite repo:
  `https://s3-us-west-2.amazonaws.com/ai2-s2-research/scicite/acl-arc.tar.gz`
- Used for **cross-dataset** verification (6 classes) to show the method
  generalises beyond SciCite. Download with `--include-acl-arc`.
